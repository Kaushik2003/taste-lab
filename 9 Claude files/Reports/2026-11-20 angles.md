## Top 3
1. **[Self-Interpretability](https://arxiv.org/abs/2505.17120)** (Plunkett 2025) · relevance 3 · monitor, section 3
   Models fine-tuned on secret preference weights can state those weights (correlation about 0.5). Training on correct reports raises this to about 0.75, also for the model's native preferences ([arXiv](https://arxiv.org/abs/2505.17120)).
   First self-report of an evaluation, not a behavior. No cross-model control, so privileged access is still open. → [[Models report preference weights trained into them (Plunkett 2025)]]
2. **[MAGELLAN](https://arxiv.org/abs/2502.07709)** (Gaven 2025) · relevance 3 · control, section 5
   An agent reads its own last-layer state to predict success, then trains on goals where its predicted success changes fastest ([arXiv](https://arxiv.org/abs/2502.07709)).
   Closest case of a hidden-state signal that controls what a model learns. The signal is competence, not taste. → [[MAGELLAN - an agent predicts its own learning progress (Gaven 2025)]]
3. **[LLMs Contain Multitudes](https://arxiv.org/abs/2606.13944)** (Trhlik 2026) · relevance 3 · evaluate, section 7 · **threat**
   Task context (news article, Reddit post, essay) shifts 37% of preference cells. Paraphrase shifts 10%. Coarse order holds; fine order moves ([arXiv](https://arxiv.org/abs/2606.13944)).
   The Stable test must include task context, not only paraphrase. → [[Task context moves model preferences (Trhlik 2026)]]

## Surprise pick
**[Processing Fluency and Aesthetic Pleasure](https://pages.ucsd.edu/~pwinkielman/reber-schwarz-winkielman-beauty-PSPR-2004.pdf)** (Reber, Schwarz, Winkielman 2004). People find things beautiful partly because they are easy to process. Typical forms win because they are easy. The effect disappears when people credit the ease to another cause.
Lesson for us: this is the human version of our main confound. A readability signal may only measure "typical for me". → [[Easy-to-process things feel beautiful (Reber 2004)]]

## Threat watch
- **Self-preference is familiarity.** Judges favor low-perplexity text whether or not they wrote it ([[Judges favor familiar text, not their own (Wataoka 2024)]]). A rising own-model premium could be sharpening, not taste.
- **Selecting by own score amplifies bias.** Self-bias grows over self-refine rounds and with best-of-k pool size, toward the model's own style ([[Self-refinement amplifies self-bias (Xu 2024)]]). Our reasoning-level control step uses the same setup.
- **Persona values decay in long chats.** Rank-order stability falls from 0.42 to 0.15 over 43 messages ([[Model values drift with persona and long chats (Kovač 2024)]]).
- **Stated preferences change with answer format** (Khan 2025, [2503.08688](https://arxiv.org/abs/2503.08688), no note).

## Which gap each angle fills (gaps in `1 Literature review/gaps.md`)
1. **Stable taste:** fills "Stability ... measured once". The Stable test now has 3 papers, 2 negative (Kovač, Trhlik).
2. **Own-model premium:** speaks to "No evidence that a model's own taste grows with self-training". Xu shows self-bias grows under self-refinement, but Wataoka says the cause is familiarity. Panickssery gives the baseline premium.
3. **Self-modifying networks:** verifies Irie 2022 and Nested Learning for the gap "no model edits its own weights by its own judgment". Both change themselves by a learned rule, with no judgment. Notes written; `TASKS.md` still holds your "in or out" call on them.
4. **Signals that control learning:** narrows "No hidden-state monitoring signal controls learning". MAGELLAN (language model, competence signal) and Backpropamine (small networks, self-set plasticity) are the closest cases.
5. **Fluency and aesthetics:** supports the typicality gap ("No probe ... checked against ... typicality"). Reber gives the theory. Nothing found that tests whether LLM code judges prefer typical code over readable code.
6. **Self-report after a weight change:** speaks to "No check that the model's self-report follows a change in its own weights". It does follow fine-tuning (Betley, Plunkett). It is still untested after a small self-edit.
