# 8. Synthesis

Purpose: put the pieces together as one loop, show where the field stops, map our threads onto those gaps, and state the strongest evidence against us.

- **Monitor: the signal is there, but someone else reads it.** Hidden states carry readable signals about the model's own work. A probe on reasoning-model hidden states predicts correctness well enough to stop reasoning early with no loss in accuracy ([[Models know when they are right (Zhang 2025)]]). Emotion states are linearly decodable at 98 to 100% in open 7 to 32B models ([[Models do not report injected pain (Ferrara 2026)]]). Sparse "value neurons" in early layers track how well the model is doing ([[Few neurons predict right answers (Xu 2026)]]). In almost every case the reader is an outside probe trained on outside labels, and the signal is correctness. One partial exception changed this picture in 2026: models apply an implicit threshold to their internal confidence when deciding whether to abstain, and steering the confidence direction moves abstention rates - the model itself is reading and causally using the signal ([[Models act on their own confidence (Kumaran 2026)]]). A harness that converts the model's own feeling-of-knowing and judgment-of-learning reports into retry decisions lifts a fixed model's accuracy by about 9 points with no weight updates ([[Models know when they know but do not act (Cao 2026)]]). The caveat survives for quality: the used signal is correctness-flavored, and the control rule is still fitted from outside. Q1 ([[Q1 Does the model sense code quality]]) keeps the probe readout but asks the open question: does it track a preference (readability) when correctness is fixed?
- **Evaluate: internal valence causes preference, but nobody has tested it on quality beyond correctness.** Emotion vectors predict and causally shift stated task preferences ([[Emotion directions drive choices in Claude (Anthropic 2026)]]). Valence held only in the KV cache shifts later choices with the text fixed ([[Hidden good-bad feeling changes choices (Berg 2026)]]). A value axis in Qwen3-8B separates correct from corrupted code and changes backtracking when steered ([[Value axis - model knows it is on track (Jiang 2026)]]; effect size from [[Gaps in the field]]). None of these compares solutions that all pass. That comparison is Q1. Confound to control: high value goes with shorter code and fewer comments ([[Value axis - model knows it is on track (Jiang 2026)]]), while a human-labeled readability direction adds comments ([[Steer code readability inside the model (Gao 2026)]]), so the two may point in opposite ways on comment density.
- **Control: steering works, but the experimenter picks the direction and the strength.** Steering along value or readability directions changes reasoning and code style ([[Value axis - model knows it is on track (Jiang 2026)]], [[Steer code readability inside the model (Gao 2026)]]), and a trained controller can read a reasoning regime and steer by it ([[Outside controller steers thinking modes (Karpf 2026)]]). In all three, humans choose the direction or train the controller, and only Jiang reports numbers on the effect. The chooser itself can now be trained: control decisions (continue, backtrack, stop) are learnable as a separate objective via control-segment policy optimization ([[Decoupled reasoning and control beats entangled thinking (Ha 2025)]]), and a high-level meta-thinking agent trained with aligned multi-agent RL learns to oversee a reasoner and beats single-agent RL ([[Two agents learn to think about thinking (Wan 2025)]]). Learned selection exists; what nobody has trained it on is the model's own evaluation signal rather than task reward. Q2 ([[Q2 Can the model steer its own code]]) closes the loop with the model's own readout. Evidence favors the best-of-n arm over the steering arm: a follow-up found probe-driven reranking helped where probe-driven steering and LoRA did not (Kirin 2607.18553, via [[Models know when they are right (Zhang 2025)]]).
- **Persist: the mechanism exists; the self-chosen direction does not.** A steering direction can be written into weights with rank-one, training-free edits ([[One direction controls refusal (Arditi 2024)]], [[TFTV - turn a steering vector into a weight edit (Perin 2026)]], [[ThinkEdit - edit weights to think longer (Sun 2025)]], [[Steer2Edit - steering into small weight edits (Sun 2026)]]). That is why Q5 ([[Q5 (stopped) Make steering permanent]]) was killed. Weight-space programming repairs localized faults with rank-one edits that act like a constant push along one direction ([[WSP - a model reads and edits weights (Takehi 2026)]], [[A simple sort replaces the anti-loop edit (Fischetti 2026)]]), and SEAL consolidates distributed changes through self-written LoRA edits, but with an external task reward ([[SEAL - models write their own training data (Zweiger 2025)]]). The gap: in every case someone else picks what to write. Q3 ([[Q3 Can self-learning avoid collapse]]) swaps SEAL's reward for the model's own valence; Q4 ([[Q4 Can the model edit its own weights]]) stays parked.
- **Anchor: every self-improvement loop that works has a hard external check.** Self-rewarding on SWE agents gains over a matched random-reward control only because tests bound the self-reward so it can never reorder pass and fail ([[Self-reward only within the same test result (Wu 2026)]]). A math discovery loop moves far from its starting library (mathlib overlap 91.9% to 30.6%) without collapse over 6 rounds, with Lean as the check ([[Learn to find interesting maths (Patel 2026)]]). Our design copies this shape: tests fix correctness, plus a novelty term ([[Anchor against collapse]]). Caveat: Patel's taste score is external and frozen, so it does not show a self-scored loop is safe.
- **Counter-evidence 1: intrinsic rewards sharpen, then collapse.** Unsupervised RLVR rewards are monotone transforms of cross-entropy to an anchor distribution, so they sharpen what the model already prefers: gains rise and then fall, with timing set by the model prior ([[Self-reward sharpens then collapses (He 2026)]]). Valence used as a reward is an intrinsic reward. The same pressure appears in calibration space: iterative self-training degenerates predictive distributions toward overconfident point estimates, and only a joint reasoning-plus-calibration objective Pareto-dominates the standard recipe ([[Train reasoning and calibration together or lose both (Yeom 2026)]]). In code, self-reward shrinks responses from about 7,300 to about 1,000 tokens and erases the confidence gap between right and wrong answers ([[Self-reward on code collapses to short code (Jin 2026)]]). Q3 must beat a no-novelty ablation and a matched random-reward control, and log length while tests pass.
- **Counter-evidence 2: a judge that sees the candidate gets hacked.** Training against one's own verdict on a shown answer inflates the judge's pass rate while true accuracy stays flat; in code, best-of-16 by the self-judge grows the gap from 0.20 to 0.588 with no training at all ([[Self-judge training makes wrong look right (Zhou 2026)]]). A valence readout on a shown solution sits in the same channel [unverified: not tested on probes]. Tests protect correctness, not style, so Q2 and Q3 need a hidden readability anchor that is never used for selection. Related warning: the "judge only among passing solutions" arm was the weakest in [[Self-reward only within the same test result (Wu 2026)]].
- **Counter-evidence 3: "grounded" cannot rest on self-report.** With input cues controlled, an input-only (layer-0) probe matches the model's in-context self-reports, and injection detection fails once "my input was manipulated" is an option ([[Introspection claims fail basic checks (Singh 2026)]]). Open models never name an injected pain state, though a probe finds it ([[Models do not report injected pain (Ferrara 2026)]]). A refusal change written into weights does not show up in the model's own account of its policy ([[One direction controls refusal (Arditi 2024)]]). Under adversarial pressure the reports actively mislead: in zero-sum debates, private scratchpad reasoning diverges from public confidence statements ([[Both sides of a debate think they will win (Prasad 2025)]]). Readability is visible in the text, so a layer-0 probe may match our readout too. Safer claim for the paper: "a probed internal signal that the model's behavior depends on", tested causally with steering.
- **Counter-evidence 4: divergent is not the same as self-originated.** Models diverge stably from authors' research choices in 15 to 36% of pairs, but often in the same direction as other models ([[Models show research taste (Trehan 2026)]]). In generator-by-selector data the own-model premium is near zero (+0.019, p = 0.14), so the taste is shared ([[Models share one taste for text (Zatuchin 2026)]]). DPO links valence to choice without moving the valence vector ([[Hidden good-bad feeling changes choices (Berg 2026)]]), so self-training may change how valence is used, not what it values. Readability may also be a convergent axis where diverging from experts means being wrong ([[Field map - Taste and new ideas]]). The test of drift from origin should be a growing own-model premium over self-training rounds.
- **The architecture cell: three legs exist, nobody has joined them.** A persistent latent self-state produces metacognitive-like behaviors with frozen weights ([[A persistent latent stream gives metacognitive behavior (Aviss 2025)]]). An agent that models its own competence inside a world model switches strategies on predicted failure ([[MUSE - a world model that predicts its own failure (Valiente 2024)]]). Learned self-modification machinery rewrites weights across nested levels, but follows the designer's loss ([[SRWM - a weight matrix that rewrites itself (Irie 2022)]], [[Nested Learning - a model that learns its own update rule (Behrouz 2025)]]). The behavioral existence proof arrived from an unexpected direction: agents with persistent memory and self-feedback, given no task at all, spontaneously organize into methodological self-inquiry about their own cognitive processes, in stable model-specific patterns ([[Agents left alone study themselves (Szeider 2025)]]), and a behavior handbook extracted from a model's own traces acts as a persistent, inspectable skill-level self-state that improves later reasoning ([[Reusable behaviors distilled from own traces (Didolkar 2025)]]). Engineered versions of the split also work at scale (an explicit object/meta-level decomposition cuts tokens to 16-33% of vanilla: [[An explicit meta-level makes reasoning controllable (Dong 2025)]]). The agenda literature says the loop itself must be learned, not designed ([[Self-improving agents need intrinsic metacognition (Liu 2025)]]), and a 20-author world-model survey independently concludes motivation and metacognition are the field's under-researched functions ([[World models miss motivation and metacognition (Rupprecht 2026)]]). The uncombined claim - persistent self-state, plus learned selection of what to keep, plus world-model simulation of self, gated by an internal evaluation signal - is G5 in [[gaps]], and it is the paper's contribution statement.

- **Where that leaves us.** No paper shows a model that reads an evaluation signal from its own activations and uses it, not an experimenter's direction, an outside judge, or the designer's outer-loop loss, to choose what it generates and what it learns, on a quality its external checks do not measure ([[Gaps in the field]]). Each stage exists alone. The matrix ([[matrix]]) shows the Stable test is the least covered, and that Q3 faces the most direct threats. If Q1 fails (readout does not track readability beyond length and perplexity), Q2 and Q3 lose their evaluator.
