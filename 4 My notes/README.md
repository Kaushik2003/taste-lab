# 4 My notes: your layer

Claude reads this folder and never writes here.

Dump rough intuitions, analogies, hunches, things that bug you, and patterns across papers you noticed and
Claude didn't. One file per idea or one running file, whatever you'll actually do.

Prompts if you're stuck:
- What did I read this week that felt *wrong*?
- What would a game designer / artist / musician say taste is?
- Where do I personally feel taste kick in when I write code?
- What's the dumbest experiment that would still surprise me?
